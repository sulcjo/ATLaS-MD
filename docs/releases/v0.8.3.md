# ATLaS-MD v0.8.3

ATLaS-MD v0.8.3 is the official release of the throughput, analysis and operator-facing work developed after v0.8.2.

## Highlights

- **Shared contact-sum CV force.** When CV2 is a residual-torsion PC over a contact CV1, the CV1 umbrella reuses CV2's contact sub-CV instead of a second copy of the pair sum: +14.6 % node throughput at 236 MPS contexts, with bias energies and forces identical to the split layout. Resumed campaigns rebuild the layout they recorded.
- **Thermodynamic energy decomposition** (ΔH / −TΔS) in `gareus-analyze`.
- **Multi-GPU umbrella pull** via `--us-pull-device-index`.
- **ATLaS-MD everywhere a person reads it.** Help (`-h`, `-hh`), the live dashboard, the monitor, console messages, report headings and plot titles use the ATLaS-MD name and carry the version; every command has `-V/--version`. Command names, the `gareus` Python package, on-disk artifacts and `GAREUS_*` environment variables are unchanged, so existing scripts, configs and campaigns keep working.
- **Dashboard.** Colour is on by default for `--tui-mode dashboard`, including in SLURM logs (`--color never` or `NO_COLOR=1` turns it off). New 2D window map: the (CV1, CV2) layout as a grid with one status glyph per λ rung. The startup wordmark is redrawn as solid block letters.

## Correctness

- Frozen-envelope Pep-GaMD production is seated in GaMD stage 5 and refuses to run otherwise; a swarm hand-off could previously leave the integrator unboosted.
- Resume from a skeleton run manifest instead of refusing an eligible segment.
- Dashboard window ranking on 2D layouts now compares true spatial neighbours (nearest windows on the same rung, in restraint-width units) and flags a window only when it is isolated. The previous flat `(w, w+1)` pairing compared windows in different cells or rungs; on a chignolin_9-shaped layout it flagged 78 of 236 windows, the new check none. This affects the dashboard's warnings only, not sampling or analysis.

## Validation

Full suite on the release branch: 3540 passed, 3 skipped, 9 failed. All 9 predate this release: 8 known failures (stale docs/example-config assertions, the Parquet-manifest smoke test, and four mutation-battery tests now stopped earlier by the correctness-core integrity guard), plus one finite-difference test that fails intermittently and passes in isolation. The release workflow additionally checks the fast exchange-kernel suite, the official package version, and a strict MkDocs build before publishing.
