# Glossary

**CV** — collective variable; coordinate restrained and sampled by windows.

**Umbrella window** — target CV center plus restraint force constant.

**REUS** — replica exchange umbrella sampling; replicas swap window assignments.

**GaMD** — Gaussian accelerated molecular dynamics; requires careful reweighting diagnostics.

**MBAR** — multistate Bennett acceptance ratio; combines biased samples into free-energy estimates.

**ESS** — effective sample size. Raw frame count can be large while weighted ESS is small.

**Frozen final production** — sampling after adaptive placement stops; preferred source for final inference.
